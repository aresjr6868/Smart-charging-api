API Endpoints
POST/api/sync
Unity gửi JSON, server hợp nhất và trả về trạng thái mới
GET/api/data
Lấy toàn bộ trạng thái server hiện tại
PUT/api/data
Cập nhật trạng thái server (Unity nhận ở lần sync tiếp)
DELETE/api/data
Đặt lại toàn bộ trạng thái server về mặc định
GET/api/logs
Lịch sử đồng bộ (?limit=N)
GET/api/status
Kiểm tra sức khoẻ và thông tin server
